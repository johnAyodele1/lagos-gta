# Lagos GTA

An open-world 3D game project inspired by Lagos, Nigeria.

## Status

Early prototype. The first milestone is a playable third-person character in a small, Lagos-inspired environment.

## Development

- Engine: Godot 4
- Initial target: desktop (Linux first)
- Rendering: Godot Compatibility renderer for broader hardware support

See [the project plan](docs/PROJECT_PLAN.md) for scope and milestones.
